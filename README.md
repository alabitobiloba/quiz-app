# Quiz App

A JavaScript quiz app that scores your answers and shows the corrections once the quiz is finished.

## Live Demo

[https://alabitobiloba.github.io/quiz-app/](https://alabitobiloba.github.io/quiz-app/)

## Features

- Scores your answers at the end of the quiz
- Shows the correct answers for the questions you got wrong
- Works on mobile screens

## Built With

- HTML
- CSS
- JavaScript

## How It Works

The quiz questions are stored in a JavaScript array. Each question is one item in that array. To add a new question, add a new item to the array and the quiz will include it automatically.
